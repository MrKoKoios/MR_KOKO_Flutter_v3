# MR KOKO Signal Pro

A Flutter trading signal analysis app for Android.

## Features
- Floating overlay icon on any broker app
- Auto-scrolls chart via Accessibility Service
- Analyses candle patterns (SMC, ICT, Price Action, OTC)
- BUY/SELL signal with confidence %
- Signal history saved locally

## Setup
1. Enable "Display over other apps" permission
2. Enable Accessibility → MR KOKO Market Scanner
3. Launch the floating icon
4. Open Quotex or any broker app
5. Tap the floating icon → ANALYSE → STOP → GET SIGNAL
